# Error Handling in Rust

A guide to error handling in Rust.

The [first half](rust-errors/README.md) introduces Rust's language features and libraries for error handling. The [second half](error-design/README.md) should help you write *good* error handling code in Rust. There's a couple of chapters in between on the [error handling ecosystem](ecosystem.md) and [recovering from errors](recovery.md).

Authored by [Nicholas Cameron](https://www.ncameron.org/)[^availability] (@nrc). To report bugs, mistakes, or feedback, visit the [source repo](https://github.com/nrc/error-docs).
